# Flujos de negocio

## Reparación

1. Buscar o registrar cliente por teléfono.
2. Capturar equipo, falla, estado físico y observaciones.
3. Generar folio `REP-0001` y registrar anticipo si existe.
4. Avanzar por diagnóstico, autorización, reparación, prueba y entrega.
5. Liquidar saldo y generar garantía.

## Venta rápida

1. Buscar producto y validar existencias.
2. Capturar cantidad y método de pago.
3. Generar folio `VTA-0001`.
4. Descontar stock y registrar movimiento.
5. Mostrar nota imprimible.
