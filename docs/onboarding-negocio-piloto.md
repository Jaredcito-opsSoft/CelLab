# Onboarding del negocio piloto

1. Configurar identidad, moneda, zona horaria, mensajes de ticket y garantía.
2. Activar únicamente módulos necesarios para la primera semana.
3. Crear un administrador nominal y un usuario por operador; desactivar credenciales de instalación.
4. Cargar categorías, catálogo, costo, precio, existencia y mínimo; contar físicamente una muestra.
5. Crear entre 1 y 10 cajas físicas con código estable y definir qué dispositivo usa cada una.
6. Probar apertura, venta en efectivo, transferencia, tarjeta y pago mixto.
7. Probar devolución parcial, apartado, reparación con pieza, impresión y rastreo público.
8. Hacer corte exacto y validar reportes contra los comprobantes.
9. Capacitar el protocolo cuando internet falla o una venta queda incierta.
10. Iniciar el piloto con un catálogo y personal limitados; ampliar después de tres cierres consecutivos conciliados.
